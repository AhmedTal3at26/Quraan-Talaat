# مصحف الخطاط طلعت فتحي محمد — موقع القراءة

موقع ويب (PWA) يعرض المصحف الشريف بخطّ الخطاط **طلعت فتحي محمد** كما هو في الأصل،
مع فهرس سور/أجزاء، وبحث في نصّ المصحف، وتنقّل مباشر إلى أي آية.

---

## التشغيل

```powershell
python tools\serve.py          # ثم افتح  http://localhost:8000
```

> يجب التشغيل عبر خادم (وليس فتح `index.html` مباشرة) لأن المتصفّحات تمنع
> طلبات الملفّات خارج مساره، ولأن عامل الخدمة (Service Worker) يحتاج `http` أو `https`.

المنفذ الافتراضي 8000، ويمكن تغييره: `python tools\serve.py 9000`

---

## المزايا

| الميزة | الوصف |
|---|---|
| عرض الصفحات | صفحة واحدة أو وجهان متجاوران (بوضعية الكتاب من اليمين/اليسار) |
| تكبير وتحريك | باللمس، بالعجلة، والنقر المزدوج (حتى ×٤) |
| التنقّل | سحب بالإصبع، أسهم لوحة المفاتيح، مسStrip المصغّرات، إدخال رقم الصفحة |
| الفهرس | ١١٤ سورة + ٣٠ جزءًا، مع القفز المباشر |
| البحث | بحث في نصّ المصحف كاملًا مع تجاهل التشكيل، ويقفز إلى موضع الآية ويضيئ علامتها |
| العلامات | حفظ مواضع القراءة والرجوع إليها |
| الوضع الليلي | ليلي/نهاري + تحكم في السطوع |
| الاستماع | مفتاح جاهز لتشغيل تلاوة الآية (يتطلب إنترنت) |
| PWA | يعمل دون إنترنت بعد أول تحميل، ويمكن تثبيته على الجوال/الكمبيوتر |

الاختصارات: `→` `←` تنقّل، `مسافة`/`PageUp`/`PageDown` صفحات، `Home`/`End` الأول/الأخير،
`Esc` إغلاق النوافذ، نقر مزدوج للتكبير.

```powershell
Remove-Item assets\mushaf -Force
tools\copy_mushaf.ps1          # أو انسخ المجلد يدويًا باسم assets\mushaf
```

## كيف بُني الفهرس؟

ملفات PDF **بدون طبقة نصّية** (الصفحات صور/متجهات)، لذلك بُني الفهرس آليًا:

1. **كشف زخارف أرقام الآيات** — لكل زخرفة توقيع هندسي ثابت
   (٢٢٫٧٥ × ٢٧٫٢٥ نقطة، كثافة ٠٫٢٩) سُمّي «الزخرفة».
   رُصدت **٦٢١٤** زخرفة في ٦٠٣ صفحة.
2. **المشي التسلسلي** — الآيات متتابعة في المصحف، فتراكم الزخارف يعطي
   رقم الآية العام لكل صفحة، ثم يُحوَّل إلى (سورة، آية) عبر جدول أعداد الآيات.
3. **ضبط الانزياح** — المجموع الكلي ٦٢٣٦ آية، فيُوزَّع الفارق على الصفحات.

النتيجة في `data/mushaf-index.json`، وقد تحقّقت يدويًا من أول الصفحات:
صفحة ١ = ١:١–٧، صفحة ٢ = ٢:١–٥، صفحة ٣ = ٢:٦–١٦، صفحة ٤٩ = آخر البقرة وبداية آل عمران.

## اتجاه القراءة (يمين ← يسار)

الموقع يعمل افتراضيًا باتجاه **من اليمين إلى اليسار** مثل الكتاب الورقي:

| العنصر | السلوك في RTL |
|---|---|
| صفحتان متجاورتان | الصفحة **الأسبق على اليمين**، والأحدث على اليسار |
| زر التقدّم | على **اليسار** (سهم يشير لليسار) |
| زر الرجوع | على **اليمين** (سهم يشير لليمين) |
| لوحة المفاتيح | `←` للصفحة التالية، `→` للصفحة السابقة |
| شريط المصغّرات | يبدأ من اليمين (الصفحة الأولى) |
| السحب بالإصبع | السحب لليمين = الصفحة التالية |

لتغيير الاتجاه إلى «من اليسار إلى اليمين»: **الإعدادات ← اتجاه الكتاب**.
عندها تنقلب ترتيب الوجهين وأزرار التنقّل تلقائيًا.

**اتجاه السحب منفصل عن اتجاه الكتاب**، وعنده خياران في **الإعدادات ← اتجاه السحب**:

| الخيار | لليسار | لليمين |
|---|---|---|
| **السحب لليمين = التالي** (الافتراضي) | السابق | **التالي** |
| السحب لليسار = التالي | **التالي** | السابق |

يُعرض التلميح «اسحب … : التالي» مرة واحدة على أجهزة اللمس، ويختفي بعد أول سحب.
لتسجيل إن كنت تشغّل النسخة الأحدث: **الفهرس ← عن المصحف ← نسخة الموقع**.

## العرض على الجوال

| العنصر | السلوك |
|---|---|
| نمط العرض الافتراضي | **صفحة واحدة** على الشاشات الأضيق من ٧٠٠ بكسل، ووجهان على غيرها |
| شريط التحكم | مثبَّت أسفل الشاشة دائمًا باستخدام `100dvh`، فيظهر كاملًا حتى مع شريط عنوان المتصفح |
| آ*iPhone* | تُحترم المنطقة الآمنة `safe-area-inset` أعلى وأسفل |
| التكبير | بالقرص (pinch) أو النقر المزدوج، مع منع خروج الصفحة عن الشاشة |
| شرائطا المصغّرات والتلاوة | لا يتداخلان: يظهر أحدهما عند عرض الآخر |

## النشر

الموقع ملفات ثابتة، فيكفي رفع المجلد كما هو على أي استضافة تدعم
`Content-Type: image/webp` (GitHub Pages / Netlify / Cloudflare Pages / Vercel).

حجم النشر ≈ ١٥٠ ميجا (غالبًا `pages/`). إن أردت نشرًا أخف، أعد الرسم بمقياس أصغر.

**مهم:** إن نشرت دون مجلد `assets/mushaf` فسيعمل الموقع في وضع الصور
(وهو الافتراضي). وضع «رسم مباشر من PDF» في الإعدادات يحتاجه فقط.

بعد أي تعديل على الملفات، ارفع رقم الإصدار في `sw.js` (`const VERSION`) ليتحدّث
المتصفّح تلقائيًا.
